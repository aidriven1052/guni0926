# 🎁 CP Decide - 쿠팡 리뷰 랜딩 페이지

틱톡, 유튜브 프로필 링크용 상품 리뷰 랜딩 페이지 템플릿입니다.

## ✨ 특징

- 📱 **모바일 최적화** - 틱톡/유튜브 사용자에게 완벽한 반응형 디자인
- 🎨 **깔끔한 디자인** - 그라데이션 배경과 카드 레이아웃
- ⚡ **쉬운 관리** - 상품 정보만 추가하면 자동으로 카드 생성
- 🛒 **쿠팡 제휴** - 제휴 링크 연동 간편
- 🔥 **할인 배지** - 할인율이 눈에 띄게 표시

## 📁 파일 구조

```
├── index.html      # 메인 랜딩 페이지 (워드프레스에 붙여넣기)
└── 사용방법.md     # 자세한 사용 설명서
```

## 🚀 빠른 시작

1. `index.html` 파일 열기
2. 소셜 미디어 링크 수정
3. 상품 배열에 본인의 상품 정보 추가
4. 워드프레스 커스텀 HTML 블록에 전체 코드 복사/붙여넣기

자세한 사용 방법은 `사용방법.md` 파일을 참고하세요!

## 📷 미리보기

- 반응형 그리드 레이아웃
- 소셜 미디어 버튼 (틱톡, 유튜브, 인스타그램)
- 상품 카드 (이미지, 할인율, 리뷰 배지)
- 쿠팡 링크 버튼
